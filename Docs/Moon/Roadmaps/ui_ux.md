# Roadmap: UI/UX

## 1. Core HUD

Define the core HUD's data contract (what gameplay state it reads) before building UMG layout — see `.agent/rules/ui_hud.md`.

## 2. Menus & Settings

Main menu, pause menu, settings/options screens — track scope and any platform-specific requirements (controller nav, safe zones) here.

## 3. Accessibility

Track accessibility requirements (colorblind modes, remappable input, subtitle/caption support) here as they're scoped — cheaper to design in from Phase 1 than retrofit.
